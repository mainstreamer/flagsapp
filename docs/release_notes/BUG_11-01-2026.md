  Tiple /scores submission upon game end 
  Root Cause

  gameOver() was being called multiple times when the game ended:
  1. From answer() when the 3rd mistake is made (correct request with answers)
  2. From componentWillUnmount() when component unmounts
  3. From redirect() (Toast's onClose handler) or other navigation paths

  After the first call, this.answers was cleared, causing subsequent calls to send empty arrays.

  Fix

  Added a gameEnded flag to prevent duplicate score submissions:

  1. Line 23: Added gameEnded = false; class field
  2. Line 126-132: gameOver() now checks the flag and returns early if already ended
  3. Line 112: startGame() resets the flag so restart functionality works

  Now only the first gameOver() call will submit the score, and subsequent calls will be ignored.
